# Contributing

LENS is a working collaboration, and this repository is meant to accumulate what the group
produces — notes, slides, code, and worked examples.

## Meeting notes

Add notes under `meetings/` as `YYYY-MM-DD-<group>.md`, where `<group>` is `lens` (monthly) or
`prism` (weekly). A short agenda plus what was discussed is enough; these are working notes,
not minutes.

## Code and worked examples

Small, self-contained examples are welcome directly in this repository. Anything substantial —
a method implementation, a package, a paper's reproduction materials — should get its own
repository in the organization and be linked from the README rather than vendored here.

## A note on data

Do not commit data that is not yours to share. Several members work with Tribal, clinical, or
restricted surveillance data governed by data-use agreements. Where original data cannot be
shared, prefer synthetic data that reproduces the analysis structure.

## How to propose something

Open an issue. For anything larger than a typo, an issue first is easier than a surprise pull
request.
