# Meetings

Agendas and working notes from LENS Monthly and PRISM weekly meetings.

One file per meeting, named `YYYY-MM-DD-<group>.md`, where `<group>` is `lens` (monthly) or
`prism` (weekly) — for example `2026-10-06-lens.md`. A short agenda plus what was discussed is
enough; these are working notes, not minutes.

This repository is public, so keep unpublished results and anything shared in confidence out of
the notes.
